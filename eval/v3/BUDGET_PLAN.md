# v3 在线评测与录制预算清单

批准总上限：USD 5；模型 gpt-6.1-sol / low；service_tier=default。

| 批次 | 预定工作 | 计划分配上限 |
| --- | --- | --- |
| 冻结回归 | 全部 13 个语义用例及 C3 两次额外重复 | $1.50 |
| 路由对照 | A1–A4 强制完整 / 自动路由 / 全文单轮；自动结果复用回归 | $1.00 |
| 多文件与真实演示 | Pydantic AI/Agno、Python MCP、安全执行对照、凭据与指令对照；三工作流追问/导出/回放 | $1.75 |
| 修复后复验 | 保留首轮失败，针对必要修复重新运行及恢复 | $0.75 |

分配用于规划；实际执行受统一总额控制，不在每个脚本或重试时重置。每个调用的 label、角色、请求大小/哈希、耗时、实际 usage 和费用状态写入 `.evidence-data/v3-budget.json`；交付时复制脱敏记录到本目录。

按 [官方模型价格](https://developers.openai.com/api/docs/models/gpt-6.1-sol)（2026-11-13 查询），短上下文标准输入 $2/M、30 分钟缓存写入 $2.50/M、输出 $10/M。预算保守地按所有输入 $2.50/M、输出 $10/M 估算，不抵扣缓存命中。每次发送前按请求字节数加余量及最大 2048 输出预留；未知调用保留预留费用。已有预留加估算超过 $5 时不发送请求。结果记录估算与未知预留，账户实际账单另计。

评测保留初次失败和后续恢复，全文输入超过现有 24,000 bytes 上限时单列为超限，不纳入节省比例。没有预填性能结果。
