# 简历项目经历

**RepoAudit-Agent｜开源框架架构调查与部署适配工作台**
技术栈：Python 3.11、FastAPI、Pydantic v2、HTTPX、SQLite WAL、OpenAI Responses / Function Calling、SSE、原生 JavaScript、GitHub Actions。

[在线演示](https://billionsheep.github.io/repoaudit-agent/) ｜ [项目源码](https://github.com/billionsheep/repoaudit-agent)

- 针对开源框架引入时实现信息分散、模型配置难追踪和环境要求难比较的问题，构建架构研报、安全线索审计、部署适配三种工作流，打通候选发现、固定版本取证、逐项判断、原文追溯与多轮追问。
- 设计 Lead/Sub 单仓上下文隔离与确定性快速路由，构建8类只读取证工具；使用 Python AST 定位参数、跨行调用及字典参数转交，按当前请求实际可见原文去重，在固定预算内保留关键语句并自动补查。
- 基于 commit、原始行号和 SHA-256 构建证据链，校验跨仓引用、摘录与派生产物；区分证据支持、明确冲突、具体风险和资料不足。基于 SQLite WAL、执行租约、幂等工具回执实现检查点恢复与持久化事件流。
- 使用原生 SVG、证据抽屉和可复制配置增强报告，支持 Markdown 与兼容旧格式的 Replay 导出；提供3份新真实双轮回放并保留3份历史回放，完成141项后端测试、16个冻结合同及13个在线语义用例回归，形成可离线分享的交付包。

## 面试展开材料

**业务收益**：把“项目是否值得试用”转换为可复查的代码位置、约束判断和下一步操作。例如自动追踪 Pydantic AI 与 Agno 的 `base_url` 参数转交；给出 Python 环境和模型网关配置；把 MCP 进程调用和环境继承列为待复核线索，避免泛化成漏洞。

**实际解决的工程问题**：关键代码被输入裁剪移出、大型索引不完整、字典到客户端构造的传递链漏查、模型输出截断、输入元数据误入输出、风险状态被误降级、回放配置引用丢失、手机端长标题溢出。可沿阶段提交和原失败录制讲解诊断过程。

**量化证据**：最终核心批次13/13满足标签与关键引用合同，C3额外2/2通过；184条新回放文件证据逐条匹配固定源码。多文件MCP架构案例仍缺服务端引用，不能把所有案例概括为完全正确。

**成本取舍**：4个小样本中自动路由比强制完整流程少11.80% Tokens，仍高于全文单轮2.510倍。建议简历主文写机制和功能，面试时用原始记录解释成本，不写泛化的降本、提速或漏洞拦截率。

**个人角色**：这是使用 Coding Agent 辅助实现的个人项目。讲述时按自己实际掌握的需求拆解、架构取舍、代码理解、验收和问题修复说明分工，避免把未参与的工作写成独立完成。
